# Invent a Word We Need — tokenxiety

One invented English word and its one-line definition:

> tokenxiety (n.): the dread that your context window fills before your task finishes.

The word names the single most shared feeling of the agent era: watching your context window fill up while the task is still unfinished. It is a clean blend of "token" and "anxiety" — sayable, spellable, memorable — and the definition is exact and self-contained, landing in one reading with no example needed.

`main.py` writes the entry to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`), with an in-program gate assertion (1–140 characters, single line, non-whitespace).
